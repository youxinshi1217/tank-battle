## 一、设计目标

为「追踪导弹」道具定制一张**开阔、有躲的乐趣**的地图：

- 玩家能跑得开，导弹有足够距离可以被绕
- 但**跑不出这张图**（四周有边界）
- 视野纵深靠「视觉三层」实现，**绝不放大地图尺寸**（`GRID_SIZE = 25`）

## 二、★ 铁律：视觉形状 == 碰撞形状 == 手绘稿形状

本关的**唯一真理**：

> **一个数都不膨胀。视觉画多大，撞上去就是多大。**

### 缺口为什么不能用极角扇形开

方格网在 0° / 45° / 22.5° 方向的采样密度不同，扇形切法导致
8 条缺口净宽 0.00~4.00 格、宽度差 4.00 格。

**正解是径向走廊**：按「到缺口中线的垂直距离 ≤ `half_w`」判定
（`|(-dx·sinθ + dy·cosθ)| <= half_w`），宽度与方向完全无关。

### 缺口侧边是直边，与碰撞判定精确等价

缺口边界 = 「到缺口中线的垂直距离 = `NOTCH_HALF_W`」的那条平行直线。
环段梯形的两个端点分别落在 r_in / r_out 圆上，两点的垂直距离都恰好
= `NOTCH_HALF_W`（因为 `sin(asin(hw/r)) = hw/r`），
所以**那条直边就是碰撞判定用的那条线** —— 角模型与垂直距离模型
完全等价，不是近似。

`span(r) = step/2 - asin(hw/r)`，`asin(x/r)` 随 r 增大而减小
→ `span_out > span_in` → **内窄外宽**（与手绘稿「梯形环段、外宽内窄」一致）。

### ★ [8] 双向断言（背景与实体一致的硬指标）

数据层函数自己验自己恒等于 0 —— 2026-10-21 的教训：「23/23 全绿」的同时
环段曾整体错位 22.5°、球胖 3.3 倍。所以 [8] 直接调 `MapRenderer`
渲染成像素，拿真碰撞函数逐格比对，**两个方向都必须为 0**：

```
方向1 隐形墙：坦克矩形真撞 -> 矩形内必须看得到墙（本体色或画在墙上的装饰色）
方向2 画大了：墙本体色像素 -> 坦克矩形放在它上面必须真撞
```

「看得见墙」= 本体色 ∪ 高光弧/暗弧/直边描线/球缘（这些颜色只出现在墙身上）；
「墙本体」= 只有实心填充色（高光/描边会探出形状外 1~2px，不算本体）。

### `notch_clear_width()` 的量法约定

- **几何点扫**（`RingGeometry.point_solid`）：早年 floor 成格子在非轴向角度上
  全量成 0；格心口径又把 96px 量成 70px
- 只从**环带中段**量到外沿：内沿处缺口是尖角，垂直扫量必读 0，是假读数
- **不把钢球算进来**：缺口正前方站着球（小球轨道 11.5 − 半径 0.85 = 外缘 10.65），
  球挡路是设计本意，不是「通道窄」

## 五、出生点规则（2026-10-23 修正）

`main.py::_pick_random_player_spawn()` 现在是三道关：

1. 格子 EMPTY ∧ 非 LJR 保护区 ∧ 3×3 邻域开放 ≥ 5（老规则）
2. **几何矩形精查**：坦克 25×25 矩形不与连续几何重叠（新增）

为什么必须加第 2 道：格子只按中心点判定，环带/钢球边缘格「格心是空的、
但坦克矩形压上去一半」—— 实测老规则 386 个候选里 **82 个（21%）会贴着墙出生**。
Stage 5 起物理走连续几何，出生点也必须用同一把尺子量。

## 九、已修的四个隐蔽 Bug（都属 pygame 行为陷阱）

### 1. 视觉走廊半宽 ≠ 碰撞走廊半宽（2026-10-21）

碰撞用 `NOTCH_HALF_W=1.50`，视觉用 `NOTCH_HALF_W + HALF_DIAG = 2.21`
→ 视觉画宽 23px → **31 格隐形墙**。已被连续几何模型彻底消除。

### 2. `BLEND_RGBA_ADD` 忽略 alpha（2026-10-21）

pygame 的 `BLEND_RGBA_ADD` 把 src 的 RGB **全量相加**、**完全忽略 src.alpha**。
水印色 `(126,92,54,72)` 加到底色 `(206,172,118)` 上直接饱和成 `(255,255,172)`
—— 一块刺眼的亮黄斑。已改为普通 blit → `(183,149,100)`，alpha 才真正生效。

### 3. `pygame.draw.circle` 像素覆盖非完美圆（2026-10-21）

`draw.circle(r=40)` 在 `(33,-22)`（dist 39.66）处**不涂**，
在 `(-33,22)` 处**涂** → 边界约 1px 不对称。绘制半径必须**向上取整**。

### 4. 方块化把圆放大一倍（2026-10-23）

格心判定让 74px 的钢球实际占 96×96px（放大 2.04 倍），
全图障碍多占 21.5 格（21%），缺口净宽从 96px 掉到 70px。
**修法：物理直接对连续几何判定**，球半径回归真实美术尺寸。
