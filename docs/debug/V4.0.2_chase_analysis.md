# V4.0.2 CHASE 转向震荡分析（debug 记录）

> 定位：本次为 **问题分析与验证记录**，非 PSA 状态快照。PSA 仅引用结论。
> 版本：V4.0.2（Turret Fairness 实施后，`enemy_tank.py` 暴露的既有行为）

---

## 现象
EnemyTank 在 CHASE 状态下，车体无法收敛对准玩家，`facing_angle` 在目标角两侧持续摆动（左右鬼畜），表现为炮口乱晃、难以命中。

## 根因
`_determine_steering()` 采用**离散 bang-bang 转向**（`steering ∈ {-1, 0, 1}`），配合：

- `ANGLE_HYSTERESIS = 15°`（`_steering_sign == ±1` → 归 0 的阈值）
- `ANGLE_DEADZONE = 5°`（仅 `_steering_sign == 0` 时生效）

**滞回(15°) > 死区(5°)**，导致系统在静止目标角附近**不存在收敛平衡点**。

## 收敛性分析
- 由 `±1` 归 0 时，`angle_diff` 已在 ∓15°（远超 5° 死区）。
- 下一帧 `_steering_sign == 0`、`|angle_diff| = 15° > 5°` → 立即重派新方向。
- 结果：`facing_angle` 在 `target ±15°~18°` 间往返，永不落入死区。

转向积分（`core/tank_physics.py::update_car`）：
```
facing += steering * turn_speed * dt
```
`turn_speed = PHYSICS_TURN_SPEED * 0.8 = 4.189 * 0.8 ≈ 3.35 rad/s`，1 帧(1/60s)约转 3.2°。

## 运行时验证证据（无头，60fps）
镜像场景（玩家每帧保持敌人正前 200px，目标角恒 0°，剔除距离/碰撞/ESCAPE）：
- `_steering_sign` 序列呈 `1 → 0 → -1 → 0 → 1 ...` 周期循环（360 帧翻转 50 次）。
- 稳态 `angle_diff` 呈锯齿波：`+17.8 → 0 → -17.8 → 0 → +17.8`，**幅度 ≈ ±17.8°**。
- 排除项：无 CHASE/RETREAT 距离切换（dist 恒 200）；无玩家移动噪声；无碰撞/physics 附加角速度。

## 修复
`_do_chase` 中，`abs(angle_diff) < math.radians(8.0)` 时强制：
```
steering = 0.0
_steering_sign = 0
```
仅在目标角 8° 内停止修正；大角度追踪行为不变；RETREAT 同样受益（倒车也能对远离方向收敛）。
